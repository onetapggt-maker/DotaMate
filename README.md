# DotaMate

Первая версия личной статистики Dota 2. React + Vite, без сервера и API-ключей.

## Что работает

- Загрузка открытого профиля по ID Dota 2, SteamID, SteamID64 или числовой ссылке Steam.
- Ранг, победы, поражения и винрейт за всю доступную историю в OpenDota.
- Последние 20 матчей с KDA, GPM, XPM, уроном, предметами и составами команд, когда эти данные доступны.
- Поиск по герою и фильтры побед / поражений.
- Статистика героев за всю доступную историю и переход к недавним матчам на выбранном герое.
- Дневник MMR: ручной ввод, график, одна запись на день.
- Отдельные записи MMR для каждого профиля в localStorage.
- Адаптивная вёрстка для телефона и компьютера.

## Запуск

Node.js 22+.

```sh
npm ci
npm run dev
```

Проверки: `npm test`. Сборка: `npm run build`. Результат: `dist/`.

## GitHub Pages

Создать репозиторий DotaMate и загрузить исходники в main. В Settings → Pages → Build and deployment выбрать GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует сайт. Относительные пути Vite поддерживают адрес вида username.github.io/DotaMate/.

## Ограничения

Нет Steam-авторизации, сервера и синхронизации между устройствами. Последний введённый ID и дневник MMR хранятся в браузере. Очистка данных сайта удалит их. MMR автоматически не определяется. Для статистики нужна общедоступная история матчей; данные могут обновляться с задержкой. Именные ссылки /id/ требуют разрешения через Steam API и пока не поддерживаются. При недоступности сводки по героям показывается статистика по недавним матчам. При недоступности OpenDota сайт показывает ошибку.

## Источники

API и каталог героев: OpenDota / odota/dotaconstants. Изображения героев: Valve Steam CDN. Dota 2 и герои принадлежат Valve. Проект не связан с Valve или OpenDota.
