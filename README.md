# DotaMate

Первая версия личной статистики Dota 2. React + Vite, без сервера и API-ключей.

## Что работает

- Демопрофиль с явно отмеченными примерными данными.
- Загрузка открытого профиля по ID Dota 2, SteamID, SteamID64 или числовой ссылке Steam.
- Последние 20 матчей из OpenDota, винрейт, KDA, GPM, XPM, детали матча.
- Поиск по герою и фильтры побед / поражений.
- Статистика героев в загруженной выборке матчей.
- Дневник MMR: ручной ввод, график, одна запись на день.
- Отдельные записи MMR для каждого профиля в localStorage.
- Адаптивная вёрстка для телефона и компьютера.

## Запуск

Node.js 22+.

```sh
npm ci
npm run dev
```

Проверки: `npm test`. Сборка: `npm run build`. Результат: `dist/`.

## GitHub Pages

Создать репозиторий DotaMate и загрузить исходники в main. В Settings → Pages → Build and deployment выбрать GitHub Actions. Workflow `.github/workflows/pages.yml` собирает и публикует сайт. Относительные пути Vite поддерживают адрес вида username.github.io/DotaMate/.

## Ограничения

Нет Steam-авторизации, сервера и синхронизации между устройствами. Профиль и дневник хранятся в браузере; очистка данных сайта удалит их. MMR автоматически не определяется. Для статистики нужна общедоступная история матчей; данные могут обновляться с задержкой. Именные ссылки /id/ требуют разрешения через Steam API и пока не поддерживаются. Статистика героев относится к последним 20 матчам, а не ко всей карьере. При недоступности OpenDota сайт показывает ошибку; настоящие данные не заменяются демоданными.

## Источники

API и каталог героев: OpenDota / odota/dotaconstants. Изображения героев: Valve Steam CDN. Dota 2 и герои принадлежат Valve. Проект не связан с Valve или OpenDota.
