# DotaMate

Русскоязычная аналитика Dota 2 на реальных публичных данных OpenDota. React, Vite, React Router, Tailwind CSS, Recharts, Lucide и Framer Motion.

## Запуск

Требуется Node.js 22+.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

## Разделы

- Поиск по SteamID64, SteamID2, SteamID3, ID друга Dota 2 или числовой ссылке Steam.
- Профиль с общей сводкой OpenDota, аналитикой последних 20 матчей, фильтрами и подгрузкой истории.
- Разбор матча с таблицами игроков, предметами, покупками, преимуществом по золоту и опыту, сражениями и вардами, когда API их возвращает.
- Каталог и страницы героев, публичные рейтинги OpenDota по героям, список профессиональных матчей.
- Сравнение за 7, 30 или 90 дней, до 100 матчей на игрока. При сбое расширенной истории оба игрока сравниваются на выборке последних 20 матчей за тот же период.
- Дневник MMR и последний открытый профиль сохраняются в браузере. MMR вводится вручную.

## Данные

В Dota 2 включи «Общедоступную историю матчей». OpenDota может обновлять историю с задержкой. Для закрытых профилей и неразобранных повторов часть полей недоступна. Именные ссылки Steam вида /id/ требуют отдельного разрешения в Steam API. STRATZ запланирован после получения официального доступа и настройки серверного API. Секреты не требуются для текущей статической сборки.

Среднее KDA — среднее по матчам от (убийства + помощь) / max(смерти, 1). Винрейт считается только по известным исходам. Общая сводка и аналитика последних матчей подписаны отдельно.

## Структура

- `src/pages` — маршруты сайта.
- `src/components` — таблицы, графики, фильтры и элементы интерфейса.
- `src/api` — запросы OpenDota, общий кэш, таймауты и обработка лимитов.
- `src/hooks` — загрузка данных и повтор запросов.
- `src/analytics.js` — расчёты и форматирование показателей.

## Публикация

В Settings → Pages → Build and deployment → Source выбери **GitHub Actions**. `.github/workflows/pages.yml` собирает проект при обновлении main и публикует `dist`. HashRouter сохраняет маршруты после перезагрузки, а относительный base Vite поддерживает путь `/DotaMate/`.
